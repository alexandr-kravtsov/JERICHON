## О проекте JERICHON

**JERICHON** — это комплексная система алгоритмического трейдинга, направленная на выявление статистически значимых закономерностей в высокочастотных данных Московской биржи (MOEX).

### Ключевые направления исследования в репозитории:
- **AFML (Advances in Financial Machine Learning):** Реализация методологии Лопеса де Прадо (Dollar Bars, CUSUM, Triple Barrier, Purged CV, Fractional Differentiation, Sample Weights).
- **Order Flow Analysis:** *Основной фокус.* Анализ потока ордеров, микроструктуры стакана и дисбалансов для прогнозирования краткосрочных движений цены. Поиск закономерностей в последовательности сделок, а не просто среди значений признаков. 
- **Nowcasting:** Прогнозирование локальных экстремумов ценового ряда.
- **Super Candles:** Исследование агрегированных свечей с расширенной микроструктурной статистикой.

### Архитектура проекта
Проект следует стандартам индустриальной разработки (Monorepo, Separation of Concerns):
- `src/` — скрипты (скачивание, хранение и обработка данных; ML-модели; бэктестинг; риск-менеджмент).
- `research/` — исследовательские .ipynb файлы с экспериментами и проверкой гипотез. Внутри разделяется на папки, каждая из которых отвечает за исследование в своем направлении.
- `data/` — хранилище данных (загружены только `sample_data` для демонстрации).
- `live/` — модуль исполнения ордеров в реальном времени.
- `app/` - UI интерфейс.

## Стек
- **Язык:** Python 3.10+
- **Анализ данных:** Pandas, NumPy, Polars
- **Машинное обучение:** Scikit-learn, XGBoost, LightGBM, CatBoost, Optuna
- **Бэктестинг и трейдинг:** Кастомный движок на Python, интеграция с MOEX AlgoPack и BCS API
- **Визуализация и UI:** Streamlit, Plotly, Matplotlib
